# Economy

**Decision:** Compute is the sole MVP currency. Capacity is a statistic that caps uncollected Compute, not a second currency.

**Proposal:** Early upgrades are instant or very short; later upgrades use short build timers. Any paid timer reduction must remain convenience-only.

**Open question:** Establish upgrade costs, generation curves, capacity cap, and offline cap through free-player playtests before adding any gamepass.
