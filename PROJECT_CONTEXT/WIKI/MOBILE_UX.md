# Mobile UX

**Decision:** The first screen must teach the loop through action, not a long tutorial; the first meaningful upgrade target is under five minutes.

**Inference:** Low visual complexity and strong feedback reduce onboarding burden.

**Open question:** Validate card layout, touch targets, and tutorial timing in a mobile Studio playtest.
