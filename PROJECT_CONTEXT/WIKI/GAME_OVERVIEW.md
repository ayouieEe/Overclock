# Game overview

**Decision:** Overclock Simulator is a simple, fair Roblox CPU-growth game for casual, mobile players. The promise is: build a CPU, let it compute, collect Compute, and improve it.

**Verified:** No gameplay or Studio behavior is verified yet. See [Playtest findings](PLAYTEST_FINDINGS.md) and [Architecture](ARCHITECTURE.md).

**Inference:** A small, readable desk-lab can be more approachable than a large world when feedback is clear.
