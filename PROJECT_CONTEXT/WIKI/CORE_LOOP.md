# Core loop

**Decision:** Check CPU → collect accumulated Compute → choose an upgrade or component → see the desk change → return later.

**Inference:** Offline accumulation, a rotating discovery point, and visible cause-and-effect are the minimum return hooks worth testing.

**Open question:** What early generation rate reaches a meaningful first upgrade in under five minutes without trivializing later upgrades?
