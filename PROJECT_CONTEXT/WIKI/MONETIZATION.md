# Monetization

**Decision:** Functional CPU progression is fully free. Gamepasses may offer shorter build timers, an extra queue, desk themes, CPU colors, and build animations only.

**Decision:** No premium-only parts, maximum stats, resources, event power, or paid random progression.

**Inference:** Convenience monetization still needs free-player progression testing to be credible.
