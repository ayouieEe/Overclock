# CPU progression

**Decision:** Cores raise base generation; Clock Speed raises a multiplier; Cache raises storage capacity; Cooling supports clock; Efficiency improves offline generation and may reduce costs slightly.

**Proposal:** The MVP has no resets, pets, trading, combat, or separate crafting system.

**Open question:** How should Cooling constrain clock upgrades while staying legible to a casual player?
